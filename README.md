# Professional Portfolio Website

A modern, fully-responsive single-page portfolio built with **React 19**, **TypeScript**, and **Material-UI**. Features smooth scroll navigation, dark/light theme toggle, scroll-triggered animations, and comprehensive sections for showcasing your experience, skills, projects, and certifications.

## Features

✨ **Modern Design** — Clean, minimalist aesthetic with Purple accent theme  
🌓 **Dark/Light Mode** — Toggle theme with localStorage persistence  
⚡ **Smooth Animations** — Scroll-triggered fade-in and slide animations  
📱 **Responsive** — Mobile-first design works perfectly on all devices  
🔍 **Organized Sections** — Hero, About, Experience, Skills, Projects, Certificates  
🔗 **Social Integration** — Links to GitHub, LinkedIn, Twitter, Email  
⚙️ **Easy to Customize** — Centralized data structure for simple content updates  

## Tech Stack

- **Frontend Framework** — React 19 with TypeScript
- **UI Library** — Material-UI (MUI) v9 with emotion styling
- **Animations** — Framer Motion + React Intersection Observer
- **Build Tool** — Vite 8 with React plugin
- **Styling** — CSS variables + Material-UI sx prop
- **Linting** — ESLint with TypeScript support
